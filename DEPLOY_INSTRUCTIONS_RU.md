# EduZan — инструкция по применению исправленного комплекта

Этот архив подготовлен из `Eduzan.github.io-main (5).zip`. Он содержит точечные исправления; исходный архив не изменён. Публикация не выполняется автоматически.

## Как безопасно применить

1. Скачайте этот ZIP и распакуйте его локально.
2. В GitHub создайте отдельную ветку от актуального `main` (например, `eduzan-repair-2026-11-26`).
3. Загрузите **содержимое папки `Eduzan.github.io-main/` целиком** в корень этой ветки, разрешив замену одноимённых файлов. Не загружайте внешнюю папку как вложенный второй уровень.
4. Откройте Pull Request в `main`; не объединяйте его, пока не проверите предпросмотр и изменения.
5. После успешного GitHub Actions проверьте русские и казахские страницы, переключатели языка, sitemap и ссылки.

## Что исправлено в этом комплекте

- добавлены переключатели РУС/ҚАЗ на русские страницы, где казахские соответствия уже существуют;
- неактивная надпись ҚАЗ на странице стипендий заменена рабочей ссылкой;
- адреса sitemap приведены к Project Pages base path `/Eduzan.github.io/`;
- в sitemap оставлены только страницы без `noindex`; казахские страницы с `noindex,follow` намеренно не включены;
- удалена повторная карточка University of Bologna — Law, Economics and Governance, сохранена более подробная версия;
- убраны фиксированные даты редакционной проверки из постоянного текста;
- резервная Stage19-копия перенесена в `_archive/` и помечена `noindex,nofollow`;
- инструкции и инвентаризация репозитория согласованы с фактическим составом архива.

## Важно

- Казахские страницы остаются `noindex,follow`: это намеренно, поскольку редакционная готовность казахских материалов ещё не подтверждена. Не удаляйте эти метатеги без отдельного решения.
- Реестр `kz/EduZan_universities_kk_verified.csv`, `.xlsx` и `kz/universities_kk_names.json` не редактировались.
- Ни один внешний сайт или GitHub-репозиторий из этого архива не изменён.
- Перед объединением PR отдельно проверьте GitHub Pages deployment и ручные пользовательские сценарии в браузере.
