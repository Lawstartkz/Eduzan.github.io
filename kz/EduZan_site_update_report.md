# EduZan — технический отчёт (подготовка файлов, НЕ публикация)

Дата: 20.11.2026. Сайт и GitHub не менялись; commit/push/PR/deploy не выполнялись.

## 1. Исходная структура (что прочитано)
Прочитаны публичные `catalog.html`, `lawstart-catalog.js` и казахская главная `kz/index.html`.
- Русский каталог: `catalog.html` (оболочка с `#q`, `#city`, `#lvl`, `#list`, `#count`, `#other`, `#olist`) + `lawstart-catalog.js`.
- Данные внутри JS: `B` (51 вуз, бакалавриат), `M` (16 записей магистратуры), `O` (доп. проверка), `W` (ссылки), `A`, `V` (5 сверенных блоков). Полей ID и казахских полей нет; ID реестра = порядок вузов в `B`, №52 — только в `M`. Рендер: одна карточка на запись `B` и отдельная карточка на запись `M` (кроме двух алиасов, склеенных с бакалавриатом).
- Казахского каталога не было: пункт меню «Каталог (әзірге орысша)» вёл на русскую страницу. Языковых словарей для каталога нет.
- Не просматривались: содержимое `data/`, `qa.json`, `lawstart-legal-kazakh.js`, прочие страницы `kz/`, `.github/workflows`. Полный обход репозитория не выполнялся.

## 2. Что сделано и почему
Русский каталог менять нельзя, поэтому создана параллельная казахская страница по той же схеме (новый HTML + новый JS в корне), без изменения существующих файлов.
- `kz/kz-catalog.html` — казахская страница (`lang="kk"`, canonical/hreflang по соглашению русской страницы, `noindex,follow` до одобрения, JSON-LD хлебных крошек). Использует классы существующего `lawstart.css`, id те же, что в русской версии. Фильтр уровня использует нейтральные ключи `B`/`M`.
- `kz/kz-lawstart-catalog-kk.js` — данные `B`, `M`, `O`, `V` скопированы дословно из `lawstart-catalog.js`; логика карточек, поиска, фильтров и сверенных блоков воспроизведена; названия вузов берутся из `data/universities_kk_names.json`.
- `data/universities_kk_names.json` — 52 записи из итогового реестра (`name_kk`, `brand_as_published`, `legal_name_kk`, статус, ссылка, примечание).

Правила отображения названия: `name_kk` → иначе бренд как опубликован → иначе русское название каталога (`lang="ru"`). №1: бренд + строка «Заңды атауы»; для partial/unconfirmed/conflict добавляется короткая пометка. №10, 20, 30, 46 название не придумывается.

Переведено на казахский (редакционный черновик): заголовки, подписи, поиск, кнопки, фильтры, пояснения о кодах и приёме, сообщения, подвал, названия городов. Остались по-русски (с `lang="ru"`): названия и примечания программ, коды, блок «Дополнительная проверка», тексты сверенных блоков — ресми қазақша атаулары не подтверждены.

## 3. Результаты локальной проверки (headless Chromium, 390 и 1280 px, локальный сервер)
- Карточек 65 (51 бакалавриат + 14 отдельных магистратуры); вузов — 52, программ — 182 (совпадает с цифрами русского каталога).
- Фильтр «Бакалавриат» — 51 карточка, «Магистратура» — 16; блок «Дополнительная проверка» скрывается при фильтре «Бакалавриат»; 5 сверенных блоков отображены.
- Все названия в данных страницы сопоставились с реестром (нет несопоставленных); пустых заголовков нет; горизонтальной прокрутки нет; все русские фрагменты помечены `lang="ru"`.
- Поиск: «Ясауи» → 1 карточка (казахское название), «Кунаева» → 1, «6B04201» → 31, «Қарағанды» → 4, несуществующий запрос → сообщение «Ештеңе табылмады…». Фильтр города: Алматы → 18; Алматы + магистратура → 6.
- Ошибки консоли: только недоступные локально ресурсы (`lawstart.css`, значки, Google Fonts).

## 4. Не проверено / ограничения
- Не запускались: опубликованный сайт, русский каталог (комплект его не меняет), автотесты (не найдены), реальные устройства, скринридер, «боевой» `lawstart.css` (внешний вид со стилями не оценён — локально CSS не загружался).
- Меню `nav.mm`, `lawstart-nav.js` и кнопка «наверх» на казахской странице не подключены: разметку казахского меню я не копировал. Переключатель языка — ссылка «Русская версия» в крошках и внизу.
- Дублирование данных: при изменении `lawstart-catalog.js` казахский скрипт нужно обновлять вручную.
- Canonical/hreflang следуют конвенции русской страницы (`https://lawstartkz.github.io/catalog.html`); она не совпадает с адресом `…/Eduzan.github.io/…`, под которым сайт сейчас открывается, — требует решения владельца.
- Тексты интерфейса, названия городов и юридические формулировки пояснений — редакционные, нужна проверка носителем/юристом; пояснения о кодах (B049/M078/M079, НЦТ) на казахском в официальных текстах не сверялись.
- Статусы и формы названий — по реестру и решениям владельца; расхождения с моими наблюдениями указаны в `EduZan_verification_report.md`.
