# EduZan 2.0

Единый GitHub-репозиторий для двух независимых модулей:

- **EduZan Portal** — публичный информационный навигатор по юридическому образованию. Статические HTML/CSS/JS-файлы публикуются через GitHub Pages.
- **EduZan Academy** — серверное приложение LMS в каталоге `academy/` (Next.js, PostgreSQL, Prisma). Размещается отдельно от GitHub Pages на сервере/платформе, выбранной для production.

## Структура

```text
/
├── *.html, *.css, *.js, *.json, images/   # существующий портал
├── kz/                                    # казахская версия портала
├── assets/, data/                         # публичные ресурсы (если используются)
├── academy/                               # самостоятельное приложение Academy
├── docs/                                  # архитектура, развёртывание, защита данных
├── scripts/prepare-pages.sh               # сборка только публичного портала для Pages
└── .github/workflows/                     # независимые процессы публикации/проверки
```

## Быстрый старт Academy

```bash
cd academy
cp .env.example .env
# заполнить локальные переменные окружения
npm install
npx prisma generate
docker compose up -d db
npx prisma migrate dev
npm run db:seed
npm run dev
```

Подробности: [`academy/README_RU.md`](academy/README_RU.md).

## Развёртывание

- Portal: GitHub Pages из ветки `main`. Workflow собирает отдельный каталог `dist/portal` и публикует только статические файлы сайта; исходники `academy/`, документация и конфигурация не попадают в Pages.
- Academy: отдельный production deployment. GitHub-репозиторий общий, процесс запуска и инфраструктура независимы. См. [`docs/DEPLOYMENT_RU.md`](docs/DEPLOYMENT_RU.md).
- PostgreSQL: production-база должна быть размещена и резервироваться в согласованной юрисдикции; перед запуском подтвердить регион БД и backup у провайдера.

## Важные продуктовые решения

- Один репозиторий, отдельные модули и независимое размещение.
- Ветка `main` — стабильная версия; `develop` — интеграционная; `feature/*` — временные ветки задач.
- В EduZan Academy **нет сертификатов, дипломов, QR-проверки и выдачи документов**.
- После успешного теста отправляется информационное email-уведомление. Результаты и история попыток сохраняются в личном кабинете. При неуспешной попытке разрешается повторное прохождение.
- Письмо о прохождении теста не подтверждает профессиональную квалификацию.

## Безопасность

Не коммитить `.env`, пароли, SMTP-ключи, production URL базы данных, персональные данные или реальные дампы БД. Использовать секреты хостинга и GitHub Actions Secrets только для соответствующих deployment-задач.
