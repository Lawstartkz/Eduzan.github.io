# Как заменить три файла в `kz/` (без публикации в обход вас)

Заменяются ровно три файла (полные версии, не патчи):
1. `kz/index.html`
2. `kz/kz-catalog.html`
3. `kz/kz-lawstart-catalog-kk.js`

Шаги (рекомендуется через ветку, не напрямую в `main`):
1. На GitHub создайте ветку, например `kz-catalog-fix`.
2. Откройте в ветке `kz/index.html` → значок карандаша → удалите всё содержимое → вставьте содержимое нового файла → **Commit changes** (в ветку). Повторите для `kz/kz-catalog.html` и `kz/kz-lawstart-catalog-kk.js`. Либо: **Add file → Upload files** → перетащите три файла в папку `kz/` (GitHub предложит перезаписать — подтвердите).
3. **Проверьте наличие `kz/universities_kk_names.json`.** Страница читает его по пути `universities_kk_names.json` (то есть из папки `kz/`). Если файла нет — загрузите его из `OPTIONAL_only_if_missing/kz/` в папку `kz/` (это данные итогового реестра, ничего не придумано). Если файл уже есть — не заменяйте.
4. Перед слиянием откройте страницы локально (`python3 -m http.server` в корне ветки) или после слияния: `/Eduzan.github.io/kz/index.html` и `/Eduzan.github.io/kz/kz-catalog.html`.
5. Слияние в `main` — только после вашей проверки.

Что не трогать: русские страницы, `kz-international.html`, `kz-kazakhstan.html`, `kz-languages.html`, `kz-legal-english.html`, `kz-lawstart-quiz-kk.js`, `kz-catalog-preview(1).html`.

Откат: на странице коммита слияния нажмите **Revert** либо верните прежние версии из истории файла (**History → Restore**).

После загрузки проверьте: меню → «Каталог» открывает казахский каталог; кнопка «Бағдарлама іздеу», карточка маршрута и ссылки в тексте ведут на `kz-catalog.html`; в EduZan Index при выборе «Қазақстан» ссылка и кнопка «Заң бағдарламасын табу» ведут на казахский каталог; в каталоге 65 карточек, строка «ЖОО — 52 · бағдарламалар — 182».
